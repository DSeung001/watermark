2저장 방식: LSB 치환

메시지 앞에 길이 4바이트를 붙이고, 그 비트를 (0,0) 픽셀부터 R → G → B 채널의 마지막 비트(LSB)에 하나씩 덮어씁니다. Alpha(투명도)는 건드리지 않습니다.

새 값 = (원래 값 & 11111110) | 넣을 비트  → 앞 7비트는 그대로, 변화는 최대 ±1

3읽을 때: 어떤 값이 워터마크인가

픽셀 값 자체에는 "이건 워터마크"라는 표시가 없습니다. 넣는 쪽과 읽는 쪽이 같은 규칙을 알고 있어서 구분합니다.

  1. 어디서: (0,0)부터 행 방향, 각 픽셀의 R → G → B 값을 차례로 봅니다. Alpha는 건너뜁니다.
  2. 무엇을: 각 값에서 마지막 1비트(LSB)만 꺼냅니다. 나머지 7비트는 원래 그림이라 무시합니다.
  3. 얼마나: 처음 32비트를 길이로 읽습니다.
  4. 나머지: 길이만큼()만 더 읽고 멈춥니다. 8비트씩 끊어서 문자로 바꿉니다.
