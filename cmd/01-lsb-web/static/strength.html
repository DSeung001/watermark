DCT 강도 T별 비교

T는 두 계수의 차이를 얼마나 벌릴지 정하는 값입니다. 같은 메시지를 T만 바꿔 넣고 화질과 훼손 내구성을 비교합니다.

1화질: T가 클수록 원본에서 멀어집니다

PSNR과 SSIM은 원본 대비 값입니다. 40dB 이상이면 눈으로 차이를 느끼기 어렵습니다. 투명 영역까지 포함한 평균이라 보이는 영역만 보면 PSNR은 더 낮습니다.

2내구성: T가 클수록 훼손을 더 버팁니다

BER은 블록을 하나씩 따로 읽었을 때 비트가 틀린 비율입니다. 다수결 복구는 적용하지 않은 값이라 T의 효과만 보입니다. 0.5는 무작위 추측과 같습니다.
